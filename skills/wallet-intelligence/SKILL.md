# Wallet Intelligence

## Principle

A wallet signal is evidence, not an instruction.

## Track

For monitored wallets:
- trades
- realized PnL
- estimated unrealized PnL
- win rate
- drawdown
- holding period
- trade frequency
- liquidity context
- asset concentration
- performance consistency

## Classification

Possible labels:
- smart money
- whale
- trader
- bot
- deployer/launcher
- market maker
- unknown

Classification must be based on observable behavior and should expose evidence.

## Anti-manipulation

Account for:
- wash trading
- self-funding
- linked wallets
- sybil clusters
- tiny sample sizes
- survivorship bias
- illiquid token marks

## Copy trading

Do not copy blindly.

Before copying:
- validate wallet quality
- validate token safety
- validate liquidity
- validate price movement
- calculate position size
- run risk checks
- log the reason

Automatically reduce or disable a wallet strategy when evidence of performance decay appears.

## AI use

AI may summarize and classify wallet behavior, but deterministic metrics remain the source of truth for financial calculations.
